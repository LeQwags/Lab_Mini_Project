# Routing Basics

Routing is the process of selecting a path for traffic in a network or between or across multiple networks.

## Core Concepts
- **Packet Forwarding**: Routers forward packets between different IP networks using a routing table. This table contains a list of destination networks and the next hop (the next router or interface) to reach them.
- **Default Gateway**: Each host on a LAN (like a PC) uses a default gateway, which is typically the IP address of the router's interface on that LAN, to reach any destination outside its own local network.
