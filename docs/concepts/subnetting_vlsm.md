# Subnetting and VLSM

Efficient IP addressing is critical for the scalability of the campus network.

## Concepts
- **Subnetting**: Breaking a large network into smaller, manageable pieces.
- **VLSM (Variable Length Subnet Masking)**: Allows you to use different masks for each subnet, ensuring that IP addresses are not wasted. For example, a point-to-point link between routers only needs 2 usable addresses (/30), while a lab might need 100 (/25).

## Mini-Project Application
You will need to calculate subnets for:
- Each department (Engineering, ICT, Admin).
- Server room hosts.
- Wireless access points and student users.
