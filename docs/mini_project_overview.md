# Mini-Project Overview: Campus Network

The mini-project applies routing ideas to a larger, more realistic enterprise network for a university annex building.

## Project Goal
Design and simulate a reliable, scalable, and secure campus network for:
- 3 departments (Engineering, ICT, Administration).
- 2 computer labs.
- 1 server room.
- Wireless access for students.

---

## Mini-Project Tasks and Concepts

### Network Design (Part A)
- Propose an overall topology (e.g., Core-Distribution-Access).
- Draw a clear network diagram.

### IP Addressing (Part B)
- Allocate IP subnets using VLSM.
- Subnets for departments, labs, servers, and wireless.

### VLAN Design (Part C)
- Create VLANs (e.g., Engineering, ICT, Admin, Students WiFi, Servers).
- Understand broadcast domain separation.

### Routing (Part D)
- Configure inter-VLAN routing (Router-on-a-stick or Layer 3 switch).
- Use OSPF or static routing.

### Services (Part E)
- Implement DHCP and DNS.

### Security with ACLs (Part F)
- Block student WiFi access to the Admin network.
- Allow student access to specific servers.

### Testing (Part G)
- Verify end-to-end connectivity and VLAN isolation.

### Final Report (Part H)
- Include diagram, IP plan, configuration summary, and justification.
