# Network Routing Lab

This repository contains the configuration, documentation, and reports for Lab 3 and the Campus Network mini-project.

## Structure

- **docs/**: Project overviews, networking concepts, and diagrams.
- **lab3/**: Configuration files and testing results for the Routing Methods comparison lab.
- **mini_project/**: Design and implementation details for the Campus Network project.
- **assets/**: Screenshots and logs.
